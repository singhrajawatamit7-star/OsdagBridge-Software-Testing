   - Submodules `bridge_types`, `bridge_components`, `loads`, `solvers`, `reports`, `cli`, and `desktop` are discoverable.
2. **Desktop Launch Command Limitation (OB-BUG-001):**
   - The documented launch command `python -m osdagbridge.desktop` fails because `desktop/__main__.py` is omitted in the official distribution.
3. **Desktop Bootstrap Implementation (OB-BUG-002):**
   - `osdagbridge.desktop.main.start()` currently executes as a console stub outputting `Starting desktop UI (stub)`.
4. **Preliminary Sizing Functionality (OB-BUG-003):**
   - Official `preliminary_sizing(dto)` currently mirrors the DTO name string rather than computing span-to-depth ratios ($L/12$ to $L/15$).
5. **Structural Design Verification:**
   - Section moment capacity ($M_d = 10,088\text{ kNm}$) and shear capacity ($V_d = 3,637\text{ kN}$) for a standard 24m plate girder conform strictly to IS 800:2007 and IRC:24 benchmark calculations.
